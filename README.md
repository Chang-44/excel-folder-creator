# Excel 文件夹批量创建工具（多级版）

一款基于 Excel 数据，**一键批量生成多级文件夹结构**的桌面工具。
支持多列组合、按数量自动展开子目录、中间层自动合并、配置保存/复用。

## 功能特性

| 功能 | 说明 |
|---|---|
| 📊 **多格式支持** | 支持 `.xlsx` / `.xls`，多 Sheet 切换 |
| 🗂️ **多级目录** | 任意选择 N 列，按顺序生成 N 级嵌套文件夹 |
| 🔢 **数量展开** | 某层可绑定"数量列"，自动生成 `1001-1 / 1001-2 / ...` 子目录 |
| 🧩 **中间层合并** | 同一父目录只创建一次，不重复（如"石家庄"只建一次） |
| 🚫 **空值跳过** | 某层值为空时，自动跳过该层，不影响后续层级 |
| 🛡️ **名称自动清洗** | 非法字符（`\ / : * ? " < > |`）、保留字、超长名自动处理 |
| 👁️ **预览优先** | 执行前先预览完整路径列表，确认无误再创建 |
| 📈 **进度显示** | 大批量创建时显示进度条，界面不卡顿 |
| 🧹 **可撤销** | 提供"清理本次创建"功能，安全回退 |
| 💾 **配置保存** | 层级配置、路径、模板可保存到 `config.json`，下次自动恢复 |
| 📝 **日志记录** | 所有操作记录到 `run.log` |
